ESTRUCTURA DE UNA ETIQUETA HTML

Las partes principales de nuestro elemento son las siguientes

  • La etiqueta de apertura: Consiste en el nombre del elemento
  • La etiqueta de cierre: es lo mismo que la etiqueta de apertura, excepto que incluye una barr
  • El contenido: este es el contenido del elemento
  • El elemento: la etiqueta de apertura, la etiqueta de cierre y el contenido forman el elemento

Los atributos contienen información adicional sobre el elemento que no desea que aparezca en el contenido real.
